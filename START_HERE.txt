  Q: 推送时提示 "Authentication failed"？
  A: 检查 Token 是否正确、未过期，且有 repo 权限

  Q: 提示 "Repository not found"？
  A: 确认已在 GitHub 创建仓库，且仓库名、用户名正确

  Q: 推送时提示 "Updates were rejected"？
  A: 先运行 git pull origin main，解决冲突后再推送

  Q: 不想用命令行？
  A: 下载 GitHub Desktop: https://desktop.github.com/
